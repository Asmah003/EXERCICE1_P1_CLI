# Exercice 5 - Correction

## 1. Commandes exécutées

Voici la listes des commandes que j'ai exécutées dans cet exercice :

 mkdir -p : Il nous permet de créer l'arborescence entière en une seule fois.

 touch : Il nous permet de créer un fichier depuis notre repertoire personnel

 echo : pour ecrire ou affiche du texte dans un fichier

 mv : Qui nous permet de renommer un fichier peut aussi nous permettre de deplacer un dossier/fichier.

 rm -r : Il nous permet de supprimer un dossier
 le -r permet de supprimer y compris le contenu du dossier : de facon "recursive".
 mais le rm est une option qui ne supprime que des fichiers.
